⚡ HydraDB

The memory layer behind every answer. Open Under the hood on any answer to see which features fired.

  • Hybrid search — semantic + keyword in one call
  • Context graphs — multi-hop paths across people, services, decisions
  • Bring-your-own-graph — exact edges for org charts & service catalogs
  • Memories — per-persona collections merged via type="all"
  • Thinking mode — query expansion for deeper traversal
